🎯 خلاصه مراحل:
═══════════════

1. npm install
2. راه‌اندازی MySQL
3. npm run init-db
4. ویرایش .env
5. تغییرات کد در index.html و app.js
6. npm start
7. باز کردن http://localhost:8080
8. ثبت‌نام اولین کاربر
9. تست قابلیت‌ها
